HOW IT WORKS
------------

1. USER UPLOADS CSV
   ├─ Frontend (TypeScript) → Sends file to backend
   └─ Backend (Python) → Saves to generated_code/Input/input.csv

2. USER ENTERS REQUEST
   ├─ "Show statistics for numeric columns"
   └─ Frontend sends to backend: analyze_request(request, metadata)

3. BACKEND PROCESSES
   ├─ Loads CSV from generated_code/Input/input.csv
   ├─ Uses CSVAnalysisAgent from your agents/ folder
   └─ Generates markdown report in project root

4. CONVERSATION DISPLAY
   ├─ Shows user request
   ├─ Shows system messages
   └─ Real-time status updates

5. RESULTS SHOWN
   ├─ Markdown report rendered in browser
   ├─ Downloadable report file
   └─ All saved in project folder

USAGE
-----

QUICK START:

1. Install Dependencies
   cd web_app
   npm install
   pip install -r requirements.txt

2. Start Application
   ./start.sh          # Linux/Mac
   start.bat           # Windows
   npm start           # Alternative

3. Open Browser
   http://localhost:5000

4. Upload CSV
   - Drag your CSV file to the upload area
   - Or click "Choose File"

5. Enter Request
   Example: "Show basic statistics for all numeric columns"

6. View Results
   - See conversation
   - View markdown report
   - Download if needed

API ENDPOINTS
-------------

POST /api/upload
  Upload CSV file
  → Saves to generated_code/Input/input.csv

POST /api/analyze
  Run analysis request
  → analyze_request(request, metadata)
  → Returns report filename

GET /api/conversation/<id>
  Get conversation history
  → Returns messages and status

GET /api/report/
  Download markdown report
  → Returns .md file
