OVERVIEW
--------
This system provides an intelligent, interactive CSV analysis platform powered
by AutoGen and LLM. You can analyze your CSV data using natural language
requests - just tell it what you want to analyze, and it generates and
executes Python code automatically!

HOW IT WORKS
------------

1. Load CSV Data
   - System loads your CSV from Input/input.csv
   - Automatically analyzes structure and metadata

2. User Makes Request
   - You type a request in plain English
   - Example: "Show statistics for numeric columns"

3. LLM Generates Code
   - AutoGen CoderAgent creates Python code
   - Uses pandas, numpy, matplotlib, seaborn
   - Saves code to generated_code/ directory

4. Code Executes Automatically
   - Results are displayed
   - Visualizations are saved
   - You see what was done

5. Iterate and Refine
   - Ask follow-up questions
   - Build on previous results

ARCHITECTURE
------------

The system uses AutoGen agents:

1. CoderAgent (AssistantAgent)
   - Generates Python code based on your requests
   - Uses pandas for data manipulation
   - Creates visualizations with matplotlib/seaborn
   - Saves and executes code

2. UserProxy (UserProxyAgent)
   - Handles user interaction
   - Passes requests to CoderAgent
   - Facilitates conversation
   - Manages code execution


CONFIGURATION
-------------

Edit config_list in any Python file:

    config_list = {
        'model': 'minimax-m2:cloud',      # Your LLM model
        'base_url': 'http://localhost:11434/v1',  # LLM endpoint
        'api_key': 'ollama',              # Your API key
        'api_type': 'openai',             # API type
    }

Supports:
  • Ollama (local LLM)
  • OpenAI (GPT-4, GPT-3.5)
  • Anthropic (Claude)
  • Azure OpenAI
  • Any OpenAI-compatible API

TROUBLESHOOTING
---------------

Issue: "CSV file not found"
  → Ensure Input/input.csv exists

Issue: "LLM connection error"
  → Check your config_list settings
  → Verify LLM service is running

Issue: "AutoGen not installed"
  → Run: pip install autogen

Issue: Unicode errors (Windows)
  → Use menu_interface.py (handles this)
  → Or set: set PYTHONIOENCODING=utf-8
